# 🏢 Property Rental Management System (PRMS)

## 🧭 About the Project
The **Property Rental Management System (PRMS)** is a **web-based application** designed to optimize the management of rental properties.  
It allows **property owners**, **managers**, and **tenants** to efficiently handle property data, maintenance requests, and apartment availability.

Built with scalability, usability, and accessibility in mind, PRMS provides a **comprehensive digital solution** for the property rental industry.

---

## ⚙️ System Features

### 👑 Property Owners & Administrators
- Manage property manager accounts (create, edit, delete profiles).
- Oversee potential tenant accounts and access activity insights.
- Maintain full control over the property management ecosystem.

### 🏗️ Property Managers
- Manage building and apartment data with real-time updates.
- Monitor apartment status and availability.
- Schedule and manage **appointments** with potential tenants.
- Communicate directly with owners and tenants.
- Report incidents or updates efficiently.

### 👥 Potential Tenants
- Register and create personalized online accounts.
- Browse and filter a **catalog of available apartments**.
- Request appointments for viewings.
- Communicate directly with property managers through the app.

---

## 🧰 Tech Stack

- **Frontend:** HTML5, CSS3, Bootstrap, JavaScript, jQuery  
- **Backend:** C#, .NET Core MVC, Entity Framework  
- **Database:** SQL Server  
- **Other Tools:** GitHub, Visual Studio, Postman
